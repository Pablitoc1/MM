# IA de draft contre les vraies drafts de la LEC 2025

Généré par `just rapport-draft` sur 308 parties de LEC 2025. À chaque tour, la vraie draft est rejouée jusque-là, puis l'IA classe les champions libres. Les équipes sont vues sans leurs champions favoris (les joueurs de 2025 ne sont pas tous dans la base) : la maîtrise des joueurs, qui compte dans le jeu, n'aide pas ici.

| Tour | Choix | Vrai choix = 1er de l'IA | Dans les 5 premiers de l'IA | Dans les 5 plus présents du patch |
|---|---|---|---|---|
| Picks | 3064 | 9 % | 36 % | 25 % |
| Bans | 3073 | 11 % | 36 % | 33 % |
