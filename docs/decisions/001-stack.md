# 001 · Technologies

Date : 10 novembre 2026. Validé par Yahia.

- Interface : Tauri 2 + React + TypeScript (Vite). Vue 2D du match en PixiJS (M6).
- Moteur et monde : Rust, dans des crates séparées de l'interface.
- Base : SQLite (M1).
- Installateurs : Windows et Mac (Yahia joue sur les deux), fabriqués par la CI GitHub. Linux aussi, pour les tests.
- Polices embarquées (`@fontsource`) : l'application marche hors ligne.
